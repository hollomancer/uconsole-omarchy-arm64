# Omarchy shell runtime lock

This layer is the smallest official Arch Linux ARM package group that is not
already guaranteed by the configured Phase 1 and exact Hyprland transactions,
but is required by the enabled Omarchy Quickshell surface.

- `packages.lock` pins the direct package versions from the frozen 2026-08-24
  `extra` database.
- `transaction.lock` is generated by the offline closure resolver and locks
  every additional official payload and detached signature by SHA-256.
- `userland.lock` pins the reproducible local, architecture-independent thin
  Omarchy package separately from official repository packages.

The local `omarchy-arm64-userland` package is built and locked separately. No
package in this layer may own the kernel, firmware, device tree, bootloader,
initramfs, `/boot`, display manager, autologin, or update policy.
